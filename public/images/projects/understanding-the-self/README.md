# Understanding the Self media checklist

- `01_teaching-plan.png` — original plan, outcomes, requirements, suggested activities, and assessment strategy
- `02_raw-content.png` — representative faculty-provided content before restructuring

- `04_philosophy-content.png` — learner-facing Socrates, Plato, and Aristotle content

- `06_knowledge-check.png` — formative assessment
- `07_reflection-activity.png` — reflection, discussion, or application task
- `08_interactive-widget.png` — OpenLearning interactive element
- `09_supplementary-media.png` — embedded video or resource
- `10_course-structure.png` — overall module and lesson organization
